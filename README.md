Public support contact: support.munibin@gmail.com.

For Apple's Support URL, use the App Support URL above. The About page also includes the contact address.

The About feature descriptions follow the supplied native app content. The reference to a web app was removed. Privacy and Terms wording was updated for the current native design, including local progress, retired accounts/sync, local prayer calculation, external place-name/content services and the current support email.

Edit the relevant index.html file to update a page, then commit to main. GitHub Pages publishes from main / (root). These are buildless static pages with local styles and the app's supplied icon; there are no visitor analytics scripts or external font requests.

This repository contains only the public website. It does not contain private native application source or credentials. Publishing these pages does not change text already bundled in an installed app.
